# 交易日课：每日 A 股复盘与考卷

公开入口：https://travelstocks.github.io/daily-trading-workbench/

配套资料站：https://travelstocks.github.io/daily-trading-review/

同一个日期下，从上到下阅读复盘摘要、查看周期与前五题材、完成决策考卷，最后导出包含原复盘章节与个人答案的报告。

## 日常工作台

- 左侧保留按月份和日期排列的复盘目录。首屏展示所选日情绪、13 项市场指标与周期节点；完整原文在本页按章展开。
- 题材区把当天前五排名、前后强度轨迹、分歧回流对照放在一起。点击题材突出对应曲线，点击格子核对来源。
- 默认「日常填写」集中为 22 个核心问题，每组问题旁边展示对应复盘资料；「完整考卷」保留原版全部题目和红线检查。
- 两个填写视图共用原字段、保存记录和报告，无需迁移旧答案。全文、完整考卷各章节和详细报告按需展开，减少重复浏览。
- 报告先显示个人周期、主线、核心与预案，再展开完整章节、原文附加资料和导出操作。
- 「当日复盘 · 六项速览」按所选日期整理大盘、情绪、题材梯队、关注标的、四种场景和交易预案。通过同日原页的结构化表格及公开计划默认值提取，不执行原站脚本，也不读取原站浏览器里的私人修改。场景保留确认/动作/撤退三项；计划保留进场/退出/最大亏损，前四项直接显示，其余可展开；完整原文默认收起但不删除。缺少资料不虚构，读取失败可重试。

## 必须保留的长期模块

页面改版不能省略原复盘站的固定内容。在市场图表之后、当日复盘和考卷之前，保留交易口诀及阶段表，并默认展开以下内容：

1. 情绪周期图：直接使用原站图片，保留所有批注，可点击放大。
2. 交易体系优缺点：舒适区和挑战区的全部条目。
3. 隔日预期表：5 列、6 行，数值按原文保留。
4. 日常知识总结：现有 17 条完整内容，后续可增加。
5. 题材节奏运行：4 个阶段、20 条判断要点。
6. 董事长交易模式专题入口，以及标明来源日期的资料库统计。
7. 连板开盘风控与第一次冲高回落止盈计算器。空值不等于零，未提供昨收价不计算价格，未提供回落点不判断承接状态。

固定文字存于 `app/handbook.json`；从原站同步使用 `npm run sync:handbook`，或 `node scripts/sync-handbook.mjs /path/to/daily-trading-review/index.html`。脚本只提取允许的文字、链接和表格，不执行源站脚本；缺少必需内容时停止，保留旧快照。同步后运行测试、构建并发布。固定手册与资料库统计采用构建快照，界面标注日期；每日行情继续实时读取原站。

计算器公式来自 `abchaoming1/limit-up-calculators-skill`。`npm test` 覆盖原脚本的基准输出、插值、边界、空值、价格和承接分类。

## 每天如何使用

1. 按原流程完成并发布每日 A 股复盘。
2. 打开工作台，选择当天日期。打开页面、回到页面或保持页面打开每 2 分钟，会检查复盘站更新；也可以手动同步。
3. 同日客观指标自动展示。考卷仅预填有明确来源的最高板、按原始强度排序的前三个研究题材。情绪、主线、仓位、盈亏、交易与反思留给本人；资料不够时留空。
4. 个人答案自动存入当前浏览器，交卷后生成可导出的统一报告。更换设备、清理浏览器前请导出 JSON 完整备份。

不需要 Sites 服务、登录或私人数据库。代码与既有公开复盘资料发布到 GitHub；个人答案仅存储在浏览器，不发送到 GitHub。关闭页面后不会后台定时运行。旧工作台记录需要先导出 JSON，再在本站导入。同日期已有个人作答不会被覆盖，自动生成的空白预填稿允许由备份替换。

## 数据规则

- 同日排名只使用同日复盘自己的强度值。历史走势可展示后续复盘引用值，并标注来源；不倒灌进当日排名。
- 自动更新只替换未被本人调整的自动答案。清空也算手动调整。归档答案冻结。
- 指数、量能、涨跌家数、板数、封板率等保留原始口径。没有同日数据就显示缺失。
- 原文观点作为资料展示，不当作本人答案。报告遵循原站章节顺序，合并个人答案，保留未填项提示。
- 资料站不可用时使用打包快照，并显示截至日期；恢复后继续读取最新页面。

## 开发与发布

Node.js >=22.13；`npm ci`，`npm test`，`npm run build`。

`npm run dev` 的地址为 http://127.0.0.1:5174/daily-trading-workbench/ 。

构建会把产物复制到 `docs/`。提交源代码与 `docs/` 后推送 `main`；GitHub Pages 使用 `main /docs` 自动发布。复盘站的日常新增文章无需重新构建本仓库，工作台会直接读取最新资料。


## 口述复盘与考卷

首页流程为市场/题材观察 → 每日复盘（六项速览和口述记录）→ 决策考卷 → 汇总报告；完整交易手册和计算器保留在报告后。

- 情绪卡和日期节点显示同日最高连板数；名称只从同日原文的“标的 / 身位”表提取与高度匹配的记录，并列全部显示，无证据标为待核实。历史多日涨停和次日晋级预案不作为当前连续板数。
- “先说复盘，再整理考卷”接收转写文字。浏览器仅按明确题目关键词匹配（例如“收盘周期是…，主线是…，仓位上限是…”），不假装具备自由语义推理能力。未识别的选择题和含糊表达不会强填。
- 自由口述可以交给对话助手，复制页面中的字段说明即可生成 `{version:1,date,answers,review:{body,next}}` 填写结果。日期必须匹配，字段、选项和长度均校验；无效项列出提示。
- 所有结果先预览，已有答案默认不勾选。只应用勾选项；应用后沿用本机自动保存、日期隔离、备份及报告生成。应用前的输入是临时草稿，切日会清空。
- 直接听写采用浏览器 SpeechRecognition / webkitSpeechRecognition，需用户点击启动并授权，可能使用浏览器服务端识别。不支持、被拒绝或识别失败时，可继续用系统听写/粘贴。未添加云端模型或 API 密钥。语音识别兼容性见 https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition 。
