# 交易日课：每日 A 股复盘与考卷

公开入口：https://travelstocks.github.io/daily-trading-workbench/

配套资料站：https://travelstocks.github.io/daily-trading-review/

同一个日期下，从上到下阅读复盘、查看周期与前五题材、完成决策考卷，最后导出 13 模块的汇总报告。

## 每天如何使用

1. 按原流程完成并发布每日 A 股复盘。
2. 打开工作台，选择当天日期。打开页面、回到页面或保持页面打开每 2 分钟，会检查复盘站更新；也可以手动同步。
3. 同日客观指标自动展示。考卷仅预填有明确来源的最高板、按原始强度排序的前三个研究题材。情绪、主线、仓位、盈亏、交易与反思留给本人；资料不够时留空。
4. 个人答案自动存入当前浏览器，交卷后生成可导出的统一报告。更换设备、清理浏览器前请导出 JSON 完整备份。

不需要 Sites 服务、登录或私人数据库。代码与既有公开复盘资料发布到 GitHub；个人答案仅存储在浏览器，不发送到 GitHub。关闭页面后不会后台定时运行。旧工作台记录需要先导出 JSON，再在本站导入。同日期已有个人作答不会被覆盖，自动生成的空白预填稿允许由备份替换。

## 数据规则

- 同日排名只使用同日复盘自己的强度值。历史走势可展示后续复盘引用值，并标注来源；不倒灌进当日排名。
- 自动更新只替换未被本人调整的自动答案。清空也算手动调整。归档答案冻结。
- 指数、量能、涨跌家数、板数、封板率等保留原始口径。没有同日数据就显示缺失。
- 原文观点作为资料展示，不当作本人答案。报告遵循原站章节顺序，合并个人答案，保留未填项提示。
- 资料站不可用时使用打包快照，并显示截至日期；恢复后继续读取最新页面。

## 开发与发布

Node.js >=22.13；`npm ci`，`npm test`，`npm run build`。

`npm run dev` 的地址为 http://127.0.0.1:5174/daily-trading-workbench/ 。

构建会把产物复制到 `docs/`。提交源代码与 `docs/` 后推送 `main`；GitHub Pages 使用 `main /docs` 自动发布。复盘站的日常新增文章无需重新构建本仓库，工作台会直接读取最新资料。
